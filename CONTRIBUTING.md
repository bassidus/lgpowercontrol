# Contributing

LGPowerControl is looking for people interested in helping maintain the project long-term — it's grown past what's easy to keep up with solo across all the distros and desktop environments it supports.

## Ways to help
* **Testing** on distros/desktop environments you use, especially outside CachyOS + KDE Plasma (the primary dev setup)
* **Triaging issues** — reproducing bugs, asking clarifying questions, confirming fixes
* **Code contributions** — bug fixes, small features

## Before you start
* Open an issue (or comment on an existing one) before starting significant work, to avoid duplicate effort
* Keep changes minimal — no new third-party dependencies, this is a deliberate project constraint
* See [ARCHITECTURE.md](ARCHITECTURE.md) for how the suspend/resume and Wake-on-LAN pieces fit together

Interested in a more active maintainer role? Open an issue or reach out.
