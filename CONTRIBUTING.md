# Contributing

## 1. Why help is needed

LGPowerControl is looking for people interested in helping maintain the project long-term. It now supports more distributions and desktop environments than one person can easily keep up with alone.

## 2. Ways to help

Testing on distributions and desktop environments other than CachyOS with KDE Plasma, the primary development setup, is one of the most useful things to contribute. Triaging issues also helps a great deal: reproducing bugs, asking clarifying questions, and confirming that fixes actually work. Code contributions are welcome too, especially bug fixes and small features.

## 3. Before you start

Open an issue, or comment on an existing one, before starting significant work, so effort is not duplicated. Keep changes minimal: no new third-party dependencies, since that is a deliberate constraint of the project. See [ARCHITECTURE.md](ARCHITECTURE.md) for how the suspend, resume, and Wake-on-LAN pieces fit together.

Interested in a more active maintainer role? Open an issue or reach out directly.
